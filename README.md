# Finxa Commerce Marketing Site

## Overview
A multi-page marketing website built using Next.js, TypeScript, and Tailwind CSS.

## Features
- Multi-page structure
- Responsive design
- Contact form with validation
- SEO metadata
- Clean UI and layout

## Pages
- Home (/)
- Pricing (/pricing)
- FAQ (/faq)
- Contact (/contact)
- About (/about)
- Privacy (/privacy)
- Terms (/terms)

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- React

## How to Run
1. Install dependencies:
   npm install

2. Start development server:
   npm run dev

3. Open:
   http://localhost:3000

## Deployment
Deployed using Vercel.

## Contact Form
Uses Formspree for handling submissions.
